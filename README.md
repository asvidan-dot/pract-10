## Мета роботи

Реалізувати локальне збереження витрат у Hive та перевірити додавання, читання, редагування й видалення записів у Flutter Web.

## Можливості

- Додавання витрат із назвою, сумою, категорією, датою та необов’язковим описом.
- Перегляд списку витрат від найновішої дати, редагування та видалення з підтвердженням.
- Аналітика за поточний календарний тиждень або місяць. Показує загальну суму, середню й найбільшу витрати, а також розподіл сум за категоріями.
- Автоматичне оновлення списку й статистики після змін у сховищі Hive.

## Запуск у Chrome

Розпакуй архів. Відкрий у VS Code папку `pr10_expenses`, у якій лежить `pubspec.yaml`. Потрібні Flutter SDK з Dart 3.7 або новішим і Google Chrome.

У терміналі VS Code виконай:

```sh
flutter pub get
flutter run -d chrome --web-port 8080
```

Для перевірки збереження онови вкладку Chrome під час роботи застосунку. Hive у браузері використовує IndexedDB. Дані прив’язані до адреси, порту й профілю браузера.

## Структура

| Файл | Призначення |
| --- | --- |
| `lib/main.dart` | Ініціалізує Hive, реєструє адаптер і відкриває box `expenses`. |
| `lib/models/expense.dart` | Задає поля моделі `Expense`, п’ять категорій і ручний `TypeAdapter`. |
| `lib/data/expense_repository.dart` | Читає список, додає записи, викликає `save()` і `delete()`. Обчислює аналітику за поточний календарний тиждень або місяць. |
| `lib/ui/expenses_screen.dart` | Показує список і діаграму. `ValueListenableBuilder` оновлює екран після змін у Hive. |
| `lib/ui/expense_form.dart` | Форма додавання та редагування. Перевіряє назву, суму й дає вибрати категорію та дату. |

## Перевірка роботи

Приклад для порожнього журналу. Для перших двох витрат обери сьогоднішню дату.

| Дія | Очікуваний результат |
| --- | --- |
| Додати «Обід» за 150 грн у категорію «Їжа» та «Проїзд» за 40 грн у категорію «Транспорт». | У списку є обидва записи. Загальна сума 190 грн, середня витрата 95 грн, найбільша витрата 150 грн. |
| Змінити суму обіду на 170 грн. | Загальна сума оновлюється до 210 грн. |
| Оновити вкладку Chrome. | Обидві витрати залишаються в журналі. |
| Видалити «Проїзд» і підтвердити дію. | Залишається «Обід» за 170 грн. |
| Спробувати зберегти витрату із сумою 0 грн. | Форма показує помилку й не зберігає запис. |

Для перевірки перемикача періодів додай витрату з датою в поточному місяці, але за межами поточного тижня, якщо така дата вже минула. Сума цієї витрати має враховуватися лише в місячній статистиці.
